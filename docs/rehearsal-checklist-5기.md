## 0. 사전 확인
- [ ] 운영 주소 접속: `[연구소 주소]`

## 1. 교사 준비 (브라우저 A)
- [ ] `연구소장(교사)` 탭에서 PIN 입력 후 입장
- [ ] 교사 연수 모드에서 기수 선택기의 **5기 (11/23 서울시교육청)** 선택
- [ ] **의뢰** 탭에 의뢰 3종이 보이는지 확인
  - [ ] 🟩 [블록] 엔트리 단계형 과제 키트 (새싹)
  - [ ] 🟦 [텍스트] 파이썬 힌트 도우미 (성장)
  - [ ] 🟪 [바이브] 생각 단계가 있는 바이브 코딩 도구 (성장)
  - [ ] 각 의뢰 설명에 의뢰인·사연·산출물·범위가 줄바꿈되어 보이는지
- [ ] **브리핑 슬라이드** 탭에 슬라이드 9장이 있는지 확인

## 2. 참가자 입장 (브라우저 B·C)
- [ ] 로그인 화면에서 **'이름으로 입장(연수)'** 탭이 기본으로 선택되어 있는지
- [ ] 안내 문구에 **교사 연수 5기**가 표시되는지
- [ ] B는 `초등_리허설1`, C는 `중등_리허설2`처럼 **서로 다른 별칭**으로 입장
- [ ] 사전 설문 → AI 윤리 서약 → 🧭 나의 가치관 작성 완료
- [ ] 의뢰 게시판에서 **B는 🟩 블록**, **C는 🟪 바이브** 선택
  - (가능하면 브라우저를 하나 더 열어 🟦 텍스트도 확인)

## 3. 단계 진행 (B·C 각자)
- [ ] **① 의뢰 분석**: 누가 · 언제 · 무엇 때문에 · 좋아지는 점 작성
- [ ] **② 설계도 작성**: 핵심 기능 하나, 화면, ✅ 수용 기준 3개 작성
  - [ ] 📈 플로우 / 🗄️ 스키마 / 📋 태스크 탭이 생성되는지 (생성 시 로딩바 표시)
- [ ] **③ AI 검토**: 질문 받기 → 답변 → 설계도 다듬기 → 다음 단계
- [ ] **④ 바이브 코딩**: 3탭 확인
  - [ ] 🧭 가치관 — `AGENTS.md` 복사·다운로드
  - [ ] 📄 설계서 — `spec.md` 복사·다운로드 (태스크·수용 기준 포함 여부)
  - [ ] ⌨️ 프롬프트 — 복사·다운로드, 모드 토글 동작
  - [ ] 외부 도구(Gemini·ChatGPT·Claude·Codex 중 하나)에 붙여넣어 결과가 나오는지 간단히 확인
- [ ] **⑤ 제출**: 수용 기준 자가 체크 → **링크 + HTML** 모두 입력 → 제출
  - [ ] HTML이 없으면 제출 버튼이 비활성인지 (필수)

## 4. 교사 화면 확인 (브라우저 A)
- [ ] **로스터**에 B·C가 보이고, 현재 단계가 실시간으로 바뀌는지
- [ ] 참가자 카드를 열어 설계도·가치관·설문 내용이 보이는지
- [ ] 🏢 **사무실 뷰**에서 접속 상태가 보이는지
- [ ] 상단 **🏆 해결 보고회 열기** → B·C 화면이 보고회로 전환되는지
- [ ] 갤러리의 **'의뢰별로 묶어보기'**로 의뢰별로 나뉘어 보이는지 (줌 화면 공유용)
- [ ] **발표회** 탭 → 🎤 발표 시작
  - [ ] B·C 화면이 발표 화면으로 동기화되는지
  - [ ] 1장이 **제목 슬라이드(제목 + 발표자 별칭)** 인지 (아니면 🔄 다시 만들기)
  - [ ] 이전/다음 발표자 이동 → 발표 종료 시 보고회 화면으로 돌아오는지

## 5. 강사 피드백 확인
- [ ] 로스터에서 B 카드 → ✍️ **피드백 초안 생성**
  - [ ] 설계–산출물 일치도·기대 효과·활동 피드백 3부분으로 나오는지
- [ ] **📣 참가자에게 보내기**
- [ ] 브라우저 B의 해결 보고회 화면 맨 위에 **📣 강사 피드백**이 보이는지

## 6. 시상 (선택)
- [ ] **🎁 시상** 탭에서 완주자 집계와 추첨이 동작하는지
